# Приглашение на день рождения 🌸

Статичный сайт: приглашение, таймер, детали, вишлист с бронью подарков и форма подтверждения.
Ответы и брони сохраняются в Google Таблицу.

## 1. Поменять данные

Имя, дата, место и дресс-код — в `config.js`.

Вишлист живёт в Google Таблице на листе **«Вишлист»** — добавляй, удаляй и меняй подарки прямо там,
сайт подхватит их при следующем открытии страницы, перезаливать ничего не нужно.

| ID | Название | Описание | Цена | Картинка (ссылка) |
|----|----------|----------|------|-------------------|
| *(оставь пустым — заполнится само)* | Духи | Любимый аромат, 50 мл | ≈ 45 000 ₸ | ссылка на картинку |

- **ID не трогай** после того, как он появился: по нему хранится бронь.
- Картинка — любая прямая ссылка на изображение (правый клик по картинке → «Копировать адрес изображения»)
  или ссылка на файл в Google Drive с доступом «Все, у кого есть ссылка». Без картинки будет 🎁.
- Строка без названия пропускается.

## 2. Подключить Google Таблицу (5 минут)

1. Создай новую таблицу на [sheets.new](https://sheets.new).
2. **Расширения → Apps Script**. Удали всё, что там есть, и вставь код из `apps-script/Code.gs`. Сохрани (💾).
   Вверху выбери функцию **setup** и нажми **▶ Выполнить** — создадутся листы «Вишлист», «Ответы», «Подарки».
3. **Начать развёртывание → Новое развёртывание**.
   - Тип (⚙️): **Веб-приложение**
   - Выполнять от имени: **Меня**
   - У кого есть доступ: **Все**
4. Нажми **Начать развёртывание**, разреши доступ (Google предупредит, что приложение не проверено: «Дополнительно → Перейти к проекту»).
5. Скопируй **URL веб-приложения** (заканчивается на `/exec`) и вставь в `config.js`:
   ```js
   scriptUrl: "https://script.google.com/macros/s/.../exec",
   ```

Чтобы снять бронь с подарка — просто удали строку на листе «Подарки».

> Если поменяешь код в Apps Script, нужно сделать **Управление развёртываниями → ✏️ → Новая версия**, иначе изменения не применятся.

## 3. Опубликовать на GitHub Pages

```bash
gh repo create birthday-invite --public --source=. --push
gh api -X POST repos/{owner}/birthday-invite/pages -f "source[branch]=main" -f "source[path]=/"
```

Через минуту сайт будет на `https://<твой-логин>.github.io/birthday-invite/`.
После правок: `git commit -am "update" && git push` — сайт обновится сам.

## Посмотреть локально

```bash
python3 -m http.server 8000
```
и открыть http://localhost:8000. Пока `scriptUrl` пустой, сайт работает в демо-режиме (всё хранится только в браузере).
